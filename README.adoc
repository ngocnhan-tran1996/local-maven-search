= Local Maven Search

A tool to search and view Javadoc directly from your downloaded files.

== Technologies

1. Java 17
2. Apache Maven 3.9.16
3. Spring Boot 4.1.1

== Getting Started

By default, downloaded Javadoc JAR files are stored in the `target/jar/downloads/` directory.
You can customize this storage location by modifying the `src/main/resources/application.yml` file:

[source,yaml]
----
app:
  jar:
    download-dir: target/jar/downloads/
----

=== Run Spring Boot Application

Execute the following command in your project root directory to start the server:

[source,bash]
----
./mvnw spring-boot:run
----

The application will start on port `8080` by default.

== API Endpoint Usage

You can access the Javadoc of any artifact using the following URL pattern:

[source]
----
http://localhost:8080/javadoc/{group}/{artifact}/{version}/{path}
----

=== Example Requests

[source]
----
http://localhost:8080/javadoc/com.google.guava/guava/33.4.8-jre/overview-summary.html
----
